STEP 01

全体像：7つの工程と、かかるお金

SNS運用を7つに分けて、工程ごとに得意なツールへ渡します。まず全体像と、始めるのに必要なものを確認してください。

SNS運用は、ひとつの大きな作業に見えて、実際は7つの工程に分かれています。分けてしまえば、工程ごとに「これは誰（どのAI）に任せるか」を決められます。

工程とツールの対応

工程使うものなぜそれか
1. リサーチClaude Code ＋ 各SNSのAPI伸びている投稿の本文と数字を、まとめて受け取れる
2. 文字起こしPLAUD ＋ Grok の文字起こしAPI自分が喋った言葉を、安く精度高くテキストにできる
3. 企画Claude Code手元のファイルを読んだうえで案を出させられる
4. 本文Claude Codeライティングの精度が高い
5. 画像Codex画像生成モデル「Image」が使える
6. 投稿Omni Socials複数のSNSへの予約投稿を、AIから指示できる
7. 分析Omni Socials ＋ Claude Code数字がたまる場所と、直す場所をつなげられる
用語：Claude Code と Codex はAIエージェント（※チャットで答えるだけでなく、パソコンの中のファイルを読んだり、作業そのものを代行したりするAI）です。どちらもデスクトップアプリがあるので、この資料はアプリで使う前提で書いています。

STEP 02

準備：デスクトップアプリでAIエージェントを開く

7工程のうち5つは Claude Code、1つは Codex で動かします。最初に、この2つをアプリで開けるところまで作ります。

Claude Code（デスクトップアプリ）

1

アプリを入れて、Claudeのアカウントでサインインする

公式サイトからMac版／Windows版をダウンロードします。ターミナル（黒い画面）を触る必要はありません。

Claude デスクトップアプリ
2

「Code」タブを開く

チャットとは別に、ファイルを読んで作業までしてくれるモードです。ここを使います。

3

最初の指示を送る前に、4つだけ決める

入力欄の周りで指定します。ここを決めずに送ると、どのファイルを読ませたいのかAI側が分かりません。

実行環境：自分のパソコン（ローカル）
作業フォルダ：次で作るフォルダを指定
モデル：最新の上位モデル（文章の質が変わります）
権限：ファイルの変更前に確認を出す設定（※慣れるまではこれが安全です）
4

材料を入れるフォルダを1つ作る

パソコンのどこでもいいので、SNS用のフォルダを1つ作ります。この中に、これから集める材料をすべて置きます。AIはこのフォルダの中だけを読みます。

SNS運用／
  ├ 過去の投稿（自分の文章を書き出したもの）
  ├ 文字起こし（喋った内容のテキスト）
  ├ リサーチ結果（伸びている投稿の一覧）
  └ ナレッジ（AIに覚えておいてほしいこと）

この「AIに読ませるための自分の情報」をまとめてナレッジと呼んでいます。最初は空で構いません。工程を進めるたびに中身が増えていきます。

Codex（デスクトップアプリ）

画像を作る工程だけ、こちらに移ります。ChatGPTの有料プランに入っていれば追加料金なしで使えます。

1

アプリを入れて、ChatGPTのアカウントでサインインする

Claude Code と同じく、パソコンの中で作業してくれるAIエージェントです。

Codex 公式
2

画像生成を呼び出せることを確認する

入力欄で $imagegen と打つと、画像生成モデル「Image」が呼び出されます。使えるモデルの名前は画面に表示されるので、最新のものを選んでください。

ポイント：2つのアプリを行き来しますが、材料の置き場所は同じフォルダ1つにしてください。本文はClaude Code、画像はCodex、と分かれていても、でき上がったものが同じ場所に集まっていれば、次の工程でそのまま渡せます。

STEP 03

リサーチ：鍵を取って、伸びている投稿をまとめて取る

企画を自分の頭の中から出さないための工程です。伸びている投稿から、何が求められているかを逆算します。

SNSで伸びている投稿は、たまたま伸びたわけではありません。見ている人が知りたかったことに当たったから伸びています。つまり何が求められているかの答えは、もうタイムラインに出ています。だから自分で考えるのではなく、伸びている投稿から需要を逆算します。

ただ、手で探すとしんどい。1本ずつ開いて、表示数を見て、メモして。20本やったらそれだけで1時間かかります。そこで使うのがAPI（※AIがそのサービスから直接データを受け取るための入り口。人が画面を開いて1本ずつ見る代わりに、AIが20本分の本文と数字を1回で受け取れます）です。

1. X APIの鍵を取る

1

開発者向けのページで、開発者アカウントを作る

普段使っているXのアカウントでサインインし、利用規約に同意して、何に使うかを記入します。特別な審査はありません。

X 開発者コンソール
2

アプリを1つ作る

名前と説明と用途を入れると、鍵が自動で発行されます。名前は自分が分かるもので構いません。

3

Bearer Token（ベアラートークン）を控える

いくつか鍵が表示されますが、公開されている投稿を読むだけなら Bearer Token 1つで足ります（※「この人からの依頼です」とXに伝えるための長い文字列）。

注意：鍵は発行した直後の1回しか表示されません。閉じる前に必ずコピーしてください。なくした場合は再発行になり、前の鍵は使えなくなります。
4

クレジットを購入する

読み取りは1件 $0.005 の従量課金（※使った分だけ払う方式）です。先にクレジットを買っておく形なので、買った分を超えて請求されることはありません。まずは最小額で試してください。

2. YouTube Data APIの鍵を取る

1

Google Cloud コンソールでプロジェクトを作る

Googleアカウントでサインインし、上部のメニューから新しいプロジェクトを作ります。名前は何でも構いません。

Google Cloud コンソール
2

「YouTube Data API v3」を有効にする

APIライブラリで名前を検索して、有効化ボタンを押すだけです。

3

認証情報からAPIキーを作る

「認証情報を作成」→「APIキー」を選ぶと、その場で文字列が出ます。公開されている動画を読むだけなら、これで足ります。

無料枠の目安：検索は1日100回まで、動画やコメントの取得は1日10,000ユニットまで。この資料のやり方なら、1日に何度リサーチしても枠内に収まります。

3. 鍵をパソコンの中にしまう

取った鍵は、チャット欄に直接貼らないでください。やり取りの履歴に残ってしまいます。代わりに、Claude Code にこう頼みます。

鍵をしまう場所を作ってもらう 
APIキーを取得したので .envファイルを作ってください

.env（ドットエンブ）（※鍵だけをしまっておく専用のファイル。AIはここを読んで使いますが、中身が画面や履歴に出ることはありません）が作られるので、そこに貼ります。以降は「Xのデータを取って」と言うだけで、AIが自分で鍵を読みにいきます。

4. 伸びている投稿を取る

Xで伸びている投稿を20本取る 
X APIを使って、「Claude Code 活用」で直近1週間に投稿されたポストのうち、
表示数が多い順に20本出してください。
本文・表示数・いいね・ブックマークも一緒に並べてください。

「Claude Code 活用」の部分を、自分が発信しているテーマに置き換えて使ってください。30秒ほどで、本文と表示数（※その投稿が画面に表示された回数。インプレッションとも呼びます）といいね、ブックマークが並んだ表が出てきます。

YouTubeで跳ねている動画を10本取る 
YouTube Data APIを使って、「Claude Code 活用」で検索して、
直近1ヶ月の動画のうち、チャンネル登録者数の3倍以上再生されているものを、
再生数の多い順に10本出してください。
なぜ「登録者の3倍以上」なのか：再生数だけで並べると、大きいチャンネルばかり出てきます。登録10万人で10万再生より、登録1万人で10万再生のほうが、企画として跳ねています。登録者に対して何倍回っているかで見ると、規模ではなく企画の強さが並びます。

5. コメント欄まで読ませる

コメント欄も同じように取れます。ターゲットの生の声がそのまま並ぶので、ここが次の企画になります。

コメント欄から、繰り返し出てくる悩みを抜く 
いま出した動画のコメントを取ってきて、
繰り返し出てくる質問と悩みを多い順にまとめてください。
実際に書かれている言葉のまま引用してください。
ポイント：出てきた結果は、必ずフォルダに保存しておいてください。次の企画工程でAIに読ませる材料になります。「いまの結果をリサーチ結果として保存しておいて」と頼めば、そのままファイルにしてくれます。

STEP 04

文字起こし：自分の言葉を材料にする

リサーチだけで作ると、競合と同じ中身になります。もう1つの材料が、自分が喋った言葉です。

自分の経験や口調は、わざわざ書き残している人がほとんどいません。でも喋っているときには、めちゃくちゃ出ています。打ち合わせ、相談に乗っているとき、雑談。書くより喋っている時間のほうが長いはずです。

だから僕は、会議も打ち合わせも録音しています。あとで見返すためではなく、発信の材料にするために録っています。

1. 録る

使っているのは PLAUD という手のひらサイズのレコーダーです。スマホでも録れますが、毎回アプリを開くのが面倒で続かないので、ボタン1個のものにしています。

PLAUD 公式

2. テキストにする

ここで使うのが Grok です。XのAIとして知られていますが、アプリをそのまま使うのではなく、Grok の音声用APIを使います。文字起こしの精度がとても高く、いま一番きれいに、お得にテキストにしてくれます。

項目内容
使うものxAI の音声文字起こしAPI（モデル名 grok-voice-transcribe）
料金音声1時間あたり $0.10（まとめて処理する場合）／$0.20（喋りながら同時に文字にする場合）
できること25以上の言語に対応。誰が喋ったかの話者分け、単語ごとの時刻付けもできます
鍵の取り方xAI のコンソールでアカウントを作り、APIキーを発行。X APIとは別の鍵です
xAI コンソール（APIキー発行） xAI ドキュメント
費用の感覚：1時間の会議で、日本円にして15円ほどです。週に5時間録っても月300円台。ここは迷わず回してください。

3. 頼み方

鍵を .env に入れたら、音声ファイルを準備のフォルダに置いて、こう頼みます。

録音を文字にして、材料として保存する 
フォルダにある音声ファイルを、Grokの文字起こしAPIで全部テキストにしてください。
話者ごとに分けて、日付が分かるファイル名で「文字起こし」フォルダに保存してください。
この工程の意味：自分の言葉をデータにしておくと、AIが自分のゴーストライティングをできるようになります。自分の言い回しで、自分の経験を書いてくれる状態です。そこにリサーチ結果が加わると、自分の言葉で、伸びる投稿が作れます。この2つが揃ってから企画に入ってください。

STEP 05

企画：AIに出させて、自分で選ぶ

企画が15割です。どんなに文章を磨いても、企画がずれていたら伸びません。

ここから Claude Code に入ります。準備で作ったフォルダを指定した状態で、こう頼みます。

企画を5本出させる 
伸びている投稿のリサーチ結果と、僕の過去の発信を読んだうえで、
X投稿の企画を5本出してください。
それぞれ、誰のどの悩みに刺さるのか、何を主張するのかも書いてください。
足りない情報は僕に質問してください。
最後の1行が効きます：AIは情報が足りないとき、それっぽく埋めて出してきます。先に質問させたほうが早いですし、答えた内容がそのまま自分の一次情報として残ります。

3つに分けて渡す

伸びている投稿を参考にするとき、丸ごと似せてしまう人が多いです。そうすると読んだ人に「これ、どこかで読んだな」と思われて終わります。だから3つに分けて渡します。

構造

伸びている投稿から

並び順、書き出し、どこで言い切っているか。型だけを借ります。

中身

自分のナレッジから

文字起こし、過去の投稿、お客さんからの質問。実際に自分が経験したことだけ。

文体

自分の過去の発信から

言い回しと改行のリズム。ここは過去の投稿からしか出ません。

選ぶのは自分

AIに決めさせるのは並べるところまでです。どれでいくかは自分で決めてください。基準は2つだけです。

  • 自分が実際に経験しているか
  • リサーチで出てきた悩みに当たっているか
選ばなかった4本も捨てない：リサーチの結果と一緒にフォルダへ残しておくと、次に作るときの判断材料になります。「不採用の4本も理由付きで保存しておいて」と言えば、そのまま残してくれます。

STEP 06

本文：自分の言葉に直すところまでやる

最初に出てきた文章は必ず直します。直し方を決めておくと、次から同じ直しが減ります。

企画が決まったら、同じ Claude Code で本文に入ります。画像を作る工程では Codex に移りますが、書く作業はClaude Codeのほうが精度が高いので、ここは移りません。

採用した企画で本文を書かせる 
採用した企画で、X投稿の本文を書いてください。
僕の過去の投稿を読んで、同じ言い回しと改行のリズムに合わせてください。
足りない情報は僕に質問してください。

ここでも、足りない情報は質問してもらいます。「この企画の読者は初心者ですか、経験者ですか」「実体験はどれを使いますか」のように聞かれるので、そこだけ答えていきます。最初から完璧な指示を書こうとしないでください。聞かれたことに答えるほうが早いです。

最初に出てきた文章の直し方

やりがちなのが「もっと僕っぽくして」です。これでは直りません。どの言葉がダメで、なぜ伝わらないのかまで書いて返します。

直らない返し方：もっと僕っぽくして／いい感じにして／もう少し刺さるように

直る返し方：3行目の「効率化できます」は、誰でも言える言葉なので削ってください。代わりに、文字起こしフォルダにある9月2日の打ち合わせで話している「1時間が30秒になった」という実例に差し替えてください。

直したあと、必ずこれを言う

同じ直しを二度させないための1行 
このフィードバックをナレッジに追加しておいて

こう言っておくと、AIが次からそれを読んでから書くので、同じ直しが減っていきます。AIは放っておくと、きれいで当たり障りのない文章を書きます。読んだ人に「誰でも書けるな」と思われたら、そこで終わりです。

STEP 07

画像：指示書を作ってから作る

ここだけ Codex に移ります。絵を描くわけではないので、デザインが分からなくても大丈夫です。

Codex 自体は Claude Code と同じで、パソコンの中で作業してくれるAIです。移る理由は1つで、Codexの中には「Image」という画像生成のモデルが入っているからです。いま一番精度が高いもので、しかもプラン契約の中で使えるので、追加料金は払わなくて済みます。

いきなり画像を作らせない

少し遠回りに見えますが、先に画像を作るための指示書を作らせます。ここを挟むだけで精度が一気に上がります。

図解の指示書をJSONで作らせる 
このX投稿の本文を読んで、1枚目に入れる図解のプロンプトをJSON形式で作ってください。
何を伝える画像なのか、入れる文言、配置、色も指定してください。

JSON（ジェイソン）（※項目ごとに区切って書いた指示書の形式）で出させると、「タイトルはこれ」「色はこれ」「入れる文字はこれ」と分かれて出てきます。人が読んでも分かる形なので、気に入らない項目だけ書き換えて渡し直せます。

作らせる

1

Codexのアプリで $imagegen を呼ぶ

出てきたJSONをそのまま貼って、画像を作らせます。

2

できた画像を、準備のフォルダに保存する

本文と画像が同じ場所にそろっていると、次の投稿工程でそのまま渡せます。

修正の頼み方：「いい感じにして」では何も変わりません。「左上のタイトルを2行に分けて、文字を大きくしてください」「背景の青をもう少し濃くしてください」のように、どこを・どうしたいかを具体的に言ってください。本文の直し方とまったく同じ考え方です。
文字の扱い：画像生成モデルは日本語の文字が崩れることがあります。図の中に長い日本語を入れるより、短い言葉だけを画像に入れて、説明は投稿の本文側に書いたほうが、結果的に読まれます。

STEP 08

投稿：予約まで持っていく（接続は5分）

本編で「つなぎ方は資料に入れておきます」とお伝えした部分です。ここだけ最初に1回設定すれば、あとはずっと日本語で指示できます。

使うのは Omni Socials です。X・Threads・Instagramなど、複数のSNSへの投稿を1か所でまとめて扱えるツールで、投稿したあとの数字もここで見られます。

ラクになるのは、AIから直接、予約投稿まで指示できる点です。投稿は出す時間で伸び方が変わりますが、その時間にスマホを触れるとは限りません。だから作ったときに「この日のこの時間に出して」まで決めてしまいます。

初回だけの設定（3つ）

1

Omni Socials に登録して、自分のSNSをつなぐ

アカウントを作り、管理画面から X・Threads・Instagram など使う媒体を追加します。各媒体でログインして許可を出すだけです（14日間の無料お試しがあります）。

Omni Socials 公式
2

AIとつなぐためのURLを確認する

設定（Settings）の中にAPIの項目があり、そこで接続用のURLとAPIキーが発行できます。AIに自分のアカウントを触らせるための、専用の入り口です。

接続用のURL：
https://mcp.omnisocials.com
3

デスクトップアプリに、そのURLを登録する

Claude のデスクトップアプリで、設定（Settings）→ コネクタ（Connectors）→ カスタムコネクタを追加と進み、上のURLを貼って保存します。そのあと Omni Socials のアカウントでサインインを求められるので、許可すれば完了です。

プロンプトの入力欄の横にある「＋」からも、つながっているコネクタを確認できます。ここに Omni Socials が出ていれば成功です。

用語：コネクタ（※AIを外部サービスにつなぐ差込口。一度つなぐと、AIがそのサービスの操作をそのまま実行できるようになります）。Codex や他のAIエージェントでも、同じURLで同じようにつなげます。
詰まりやすいのはここだけ：つなぐ作業そのものは5分で終わりますが、手順2でつまずく人はたいてい、手順1のSNS連携が終わっていません。先に投稿したい媒体を全部つないでから、AIとの接続に進んでください。
もう1つ。X の長文記事（X Articles）には対応していないので、画像つきの通常投稿で回してください。この資料の流れも、その前提で組んでいます。

つないだあとは、日本語1本

作った投稿を予約する 
さっき作った投稿を、明日の19時にXとThreadsへ予約投稿してください。

画像を上げるところも、日時を入れるところも、全部AIがやってくれます。複数の媒体に同時に出せるので、1本作ればそのまま横展開できます。

出す前に、人が確認すること

最終チェックだけは人がやってください。ここを飛ばすと、間違った時間や間違ったアカウントに出ます。

  • 予約された日時が、意図した日時になっているか（午前と午後の取り違えが一番多い）
  • 出す先の媒体とアカウントが合っているか
  • 画像が正しいものに紐づいているか、見切れていないか
  • 本文の改行が、自分の投稿のリズムになっているか
  • URLを入れた場合、実際に踏んで正しい先に飛ぶか
読み戻しのコツ：「いま予約した内容を、そのまま読み上げて確認させてください」と頼むと、登録された中身をAI側から出してくれます。自分の記憶と突き合わせるより確実です。

STEP 09

分析：結果を次の1本に戻す

出して終わりにしません。ここを回すかどうかで、3ヶ月後の差がいちばん大きく出ます。

数字は Omni Socials にたまっているので、そのまま読ませます。どこを見ればいいか迷う必要はありません。見るところの判断もAIにやらせます。

1ヶ月分の数字を、伸びた／伸びなかったで分ける 
Omni Socialsから、直近1ヶ月に出した投稿の数字を取ってきてください。
伸びた投稿と伸びなかった投稿に分けて、
何が違ったのかも書いてください。

伸びた投稿とそうでない投稿が分かれて、違いまで書かれた状態で出てきます。ここで終わらせないでください。出てきた改善点をその投稿だけ直して終わりにすると、また同じことを指摘することになります。

結果を抽象化して、これから書く全部に効かせる 
今回の投稿の結果を抽象化して、
今回だけじゃなく、今後書くすべての投稿に反映させてください。
同じ指摘をしないで済むようにしておいてください。

残し方を分ける

伸びた

何が効いたのかを残す

書き出しか、題材か、実体験の濃さか。効いた理由を1行で残して、次の企画の候補に入れます。

伸びなかった

狙いか、言い方かを分ける

そもそも需要がなかったのか、需要はあったが言い方で伝わらなかったのか。ここを混ぜると次に活かせません。

次へ

リサーチに戻る

残した判断材料を持って、またSTEP03のリサーチへ。ここで1周です。

これを繰り返すと：同じ失敗を二度しないSNS運用になります。ナレッジが厚くなるほど1回目の出力の精度が上がるので、直す時間そのものが減っていきます。

STEP 10

まとめ：今日やること／人に残す2工程

全部を一度にやろうとしなくて大丈夫です。今日は準備だけで十分です。

覚えて帰ってほしいこと

  1. 工程で分けて、工程ごとに得意なものへ渡す1つのAIに全部やらせようとすると、どこかで精度が落ちます。リサーチと企画と本文はClaude Code、画像はCodex、投稿と分析はOmni Socials。
  2. 企画を自分の頭の中から出さない答えはもうタイムラインに出ています。伸びている投稿から需要を逆算してください。
  3. 喋った言葉をデータにしておくここがあるかないかで、AIが自分の言葉で書けるかが決まります。競合と同じ中身になるのを防ぐ唯一の材料です。
  4. 直したら、必ずナレッジに返すその投稿だけ直すと、また同じ指摘をします。考え方に返すと、次から出てこなくなります。
  5. 企画を選ぶことと、出す前に直すことは手放さない逆に言えば、それ以外は全部渡して大丈夫です。

今日やることチェックリスト

  • Claude Code のデスクトップアプリを入れて、Codeタブを開く
  • SNS用のフォルダを1つ作り、作業フォルダに指定する
  • 自分の過去の投稿を20〜30本コピーして、そのフォルダに置く
  • YouTube Data API のキーを取る（無料枠で足ります）
  • STEP03のプロンプトを1本打って、リサーチ結果を出してみる
ここだけ注意：鍵（APIキー）はチャット欄に直接貼らないでください。やり取りの履歴に残ります。.env に入れて、AIにそこを読ませるのが基本です。人に画面を見せるときも、この形にしておけば事故が起きません。
全部そろわなくても始められます：最初の1周は、YouTube Data API（無料枠）＋ Claude Code だけで回せます。文字起こしと予約投稿は、1周して手応えが出てから足してください。
